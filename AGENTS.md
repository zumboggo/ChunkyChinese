# Chunky Chinese Project Notes

- The user primarily studies on a phone and often controls Active Recall with an 8BitDo Micro controller.
- The controller buttons that work reliably are keyboard numbers `3` and `4`; treat them as configurable `Choice A` and `Choice B`.
- Active Recall essentials should be possible with only Choice A and Choice B whenever practical:
  - quiz answers: Choice A / Choice B;
  - sentence continue: Choice A;
  - flashcard review: Choice A flips the card, then Choice A = Again and Choice B = Good.
- Keep other rating options available by screen tap and the remaining configured hotkeys.
- After implementing user-requested code changes, commit and push to GitHub unless the user explicitly asks not to.
