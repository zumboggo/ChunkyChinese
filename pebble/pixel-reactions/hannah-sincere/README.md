# Hannah — Gentle Warmth

Six 64×64/eight-colour reactions: blink, surprised, thinking, talking, laughing and
worried. Selected Gentle Warmth shocked/laughing references are retained in source/.
Head/body and facial patches share the approved haircut, braids, freckles and navy
shirt. Small head movement is bounded to one pixel. Every reaction finishes and
holds; individual GIFs do not loop. The overview GIF loops only for comparison.

[Interactive preview](preview/index.html) · [Animated overview](preview/six-animations.gif)

Run build.py then verify.py. Independent decoding reproduces all 31 PNG frames;
art is 2,760 bytes, timing 216 bytes, combined 2,976 bytes. Source RGB previews are
quantized to Pebble's hardware colours by the integrated reader. Native verification
is recorded separately in the release evidence. No paid generation was needed.
