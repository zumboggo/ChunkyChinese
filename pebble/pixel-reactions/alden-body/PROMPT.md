# Imagegen reference provenance

Built-in imagegen, using `../alden-sincere/blink/00.png` as the identity reference.
Output: `imagegen-reference.png`. This guides clothing continuation; the shipping
face, hair, expressions and palette remain the original assets. Production pieces
are authored on the existing logical pixel grid in `build.py`, then packed.

## Prompt

Use case: identity-preserve. Production pixel-art reference for a Pebble watch character. Extend this EXACT Alden portrait down to his waist, preserving his face, haircut, expression, charcoal hoodie, grey T-shirt, warm pale peach skin, and slender build. Front-facing, hands relaxed at sides, open hoodie. One coherent pixel-art figure, logical 64-pixel-wide grid with roughly 92 pixels height, enlarged with hard nearest-neighbour pixel edges. Continue the existing shoulders into narrow sleeves and hoodie hems; restrained one-pixel folds, matching dark brown one-pixel outline, grey shirt center, simple sleeve cuffs and hands. Use the same eight-colour aesthetic and same pixel density throughout top and bottom. Transparent background. No lettering, no scenery, no new accessories, no gradients, no antialiasing, no change to head design. This is a reference for reusable body and arm pieces; prioritize consistent clothing continuation and pixel proportions.
